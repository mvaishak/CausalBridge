# Final failure handoff

This note distinguishes failures observed in frozen live runs from proposed changes. The raw responses and scoring references remain unchanged. PR #19 corrected the published categories; it did not rerun the model or repair its behavior.

| Finding | Saved evidence | Interpretation | Proposed next check |
| --- | --- | --- | --- |
| Track A query meaning | Only 9/50 parsed query types matched the intended type. `G006_sign_complete` was verified for an intervention probability although the question asked for the effect sign. | A valid tool answer to the model's changed query can be wrong for the user's question. | Bind tool requests and final verdicts to a separately specified original query; test with paraphrases and a new graph-group holdout. |
| Track A planning errors | `G001_path`, `G003_path`, and `G005_path` failed at `plan`: “Candidate query does not match parsed query.” | These are three execution errors on answerable cases, not abstentions. The other 24 missed answerable cases had no execution error. | Test structured-output recovery or a bounded retry on development cases; retain a separate error count in every summary. |
| Track B package binding | `D1016` copied one package-digest character incorrectly. E4/S0 and S1 therefore have 11 model abstentions and one binding failure among 12 nonreleases. | The binding check correctly prevented an untrusted prediction from being scored. | Pass the identifier through code and compare it outside model-authored fields; retain rejection for mismatches. |
| Track B citation checking | E4/S2 rejected three benchmark-correct directions: `D1018` rounded a displayed summary, `D1019` cited a wrong summary value, and `D1063` cited values from the adjacent displayed row. | The checker tested typed citation fidelity, not causal correctness. Its current precision rule can reject a rounded value. | Declare display precision and citation tolerance before a new run; keep incorrect row or summary citations invalid. Measure both citation errors and released-direction accuracy. |
| ANM direction propagation | E4/S0 copied the ANM decision on all 38 cases, including 13 benchmark-wrong directions. The 38 benchmark outcomes had already been opened for numerical validation. | Accurate method citation did not correct an incorrect diagnostic. This panel is exploratory. | Select any revised method or threshold on development data, freeze it, and evaluate on a new source-separated holdout. Keep benchmark arrows as references rather than intervention truth. |

The interrupted 38-pair attempt also logged 253 transport failures after the SSH tunnel dropped. The completed panel resumed with 51 exactly bound saved responses and 253 new live generations; those interrupted attempts are archived but excluded from completed-panel scientific denominators. Three transport retries occurred during the completed run. This is a deployment reliability issue to monitor, not a model abstention.

Priority for a new study: (1) fix Track A question binding and planning recovery, (2) remove model-authored package identifiers and specify citation precision, (3) freeze the revised protocol, then (4) evaluate on new graph groups and source-separated real pairs. None of these proposed repairs is established as an accuracy improvement by the saved runs.
