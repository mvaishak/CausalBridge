The archived `session.json`, 136 `native_started` and `native_generated` events, and original responses establish live execution. The 17 pairs represent seven source groups.

PR #15 (`7c7198d`, November 18) added Anish's ANM study, numerical diagnostics, 512-row synthetic confirmation, and 38-pair real validation. The production ANM, native integration, and predictor files were unchanged from the pilot revision. The 512-row configuration was a **new validation variant**; it did not retroactively become the pilot's configuration. The 38 real benchmark directions had already been opened for that numerical validation, so they are no longer an independent holdout for method selection.

Faizah's merged work (`7aec8fd` and `a29dc4b`) completed the 108-pair roster, source-group and eligibility review, snapshot checks, evaluator joins, diagnosis accounting, and scoring-lineage checks. The loader gained source-review and hash logic; the scorer gained stricter mapping/lineage checks. The pilot's 17 selected rows, labels, weights, and model configuration were unchanged. These changes affected evaluation validity and reproducibility, but did not change the archived pilot's model-visible evidence.

The current 128-row pipeline reselected and recomputed all 17 cases offline. `scripts/audit_postmerge_track_b.py` compared all 136 original live trial starts to the current replay on case, package, and condition. A fresh 17-case inference run would therefore repeat identical requests without testing the later 512-row variant, and was not needed for the frozen pilot comparison.

## Dataset inventory and selection

The pinned Tübingen snapshot has 108 numbered pairs. The roster marks 59 scorable: 17 original pilot pairs in seven groups, four development pairs in three groups, and 38 validation pairs in 12 groups. Forty-nine are unscorable under the recorded eligibility rules. The pilot and 38-pair validation have no pair or source-group overlap. The four development pairs are not used for a final assessment. All 38 validation benchmark labels were previously examined by the numerical ANM study; no eligible, genuinely untouched source-separated panel remains in this snapshot.

The frozen integrated cohort is all 38 eligible validation-role pairs, chosen before this run without outcome-based filtering. It uses the saved `sample_512` ANM requests/results from PR #15, the current roster and loader checks, reviewed variable names in `configs/final-track-b-validation-names.json`, compact S0/S1 prompts, S2 checker replay, ANM-only, and the simple gate. The name mapping was made from source descriptions after outcomes had been opened, without using the direction fields; it is not a blinded annotation. The protocol is `configs/final-track-b-integrated-38.json`. This is an **exploratory full-panel matched evaluation**, not independent confirmation. It tests a different ANM sample size from the original 17 and must not be pooled with that pilot as if the pipelines were identical.

## Independent method review

The real ANM failure is compatible with several documented limits: an additive-noise model can be misspecified for confounded, discretized, mixed, or heterogeneous observational pairs; 128-row estimates can be unstable; source groups and benchmark arrows are not interchangeable independent causal truths. The 512-row real validation still produced 13 correct, 13 wrong, and 12 abstentions on 38 pairs, so limited sample size alone is not an established explanation. In the saved primary split, the 22 cases with all 512 rows had 9 correct, 3 wrong, and 10 abstentions; the 16 cases with fewer rows had 4 correct, 10 wrong, and 2 abstentions. This association is consistent with finite-sample difficulty, but sample size is confounded with source family and pair type. Janzing mechanics had three wrong and one abstention; Moffat ecosystem had three correct. These are descriptive post-hoc strata, not a validated diagnosis or selection rule. These mechanisms remain hypotheses rather than causal diagnoses of each failure.

The snapshot hashes, roster eligibility, original-to-runtime orientation receipts, and cached ANM request bindings all passed current validation. No data-preparation defect was found that would explain the real error pattern. This does not prove the reference arrows or observational assumptions correct.

IGCI tests a different independence-of-mechanism asymmetry and is plausible on continuous, clean, deterministic relationships, but its normalization and distribution assumptions may be difficult on this mixed benchmark. RECI compares regression errors in two directions under equal scaling, near-determinism, and independence assumptions. Neither is an assumption-free fallback. Implementing either after inspecting the 38 reference outcomes would create a method-selection problem without a new untouched cohort. A simple alternative could be an exploratory methodological comparison in a future study; it cannot now establish improved generalization. The current negative-result conclusion does not require a new baseline.
