# Research questions and protocol changes

The original project asked whether an LLM can use graph operations and numerical evidence to answer causal questions while a checker prevents unsupported releases. Track A tested graph/query interpretation and tool binding on ten synthetic graph groups. Track B tested whether richer evidence packages, an ANM directional card and a typed-claim checker improve causal-direction decisions on real pairs. The [roadmap](../knowledge/roadmap-status.md) and [final report](../../report/CausalBridge-final.md) give the original work packages.

Implementation exposed two distinct limits. Track A's model frequently planned the wrong operation despite correct structural tools. Track B's model copied wrong ANM directions and the checker verified attribution rather than causal truth. Later, opened-cohort thinking and directional-cue studies tested response behavior, while ANM follow-ups probed numerical and assumption mechanisms. These follow-ups have different prompts, budgets, outcomes and denominators. None established a validated accuracy repair. Next work needs frozen changes and a genuinely unexamined, source-separated cohort; see [limitations](limitations.md).
