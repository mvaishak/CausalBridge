# Research evidence ledger

The [research reference](CAUSALBRIDGE_RESEARCH_SOURCE_OF_TRUTH.md) uses this ledger for its main scientific claims. Track B “correct” means agreement with retained Tübingen reference directions. **Evidence verification** and **scientific inference strength** are separate: an exact saved count can have limited external validity.

Verification levels attained **in this documentation audit**:

- **V1:** Read an original plan, archived summary, manifest or verification record. A source's own `PASS` log remains V1 unless we performed a separate check.
- **V2:** Independently recounted the claim from saved case-level records, evaluator mappings or raw-trace fields. This reuses saved model/numerical outputs.
- **V3:** Deterministically replayed evaluation code against saved records into a new temporary output and compared the result. This is still an offline replay, not new model inference.
- **V4:** Independently recomputed against a separate mathematical or numerical reference. Only the exact analytical witness attained this level here.

For documentary provenance and absent-source claims, V1 means direct inspection of the named original document or checkout inventory. It does not imply an experimental reproduction. A higher level includes the lower-level source inspection where applicable. The raw archive may contain original observations while the linked case table is a derived output; both are named when the distinction matters.

## Recount boundary

The V2 checks reclassified or rescored **saved outputs**. They are independent of the published summary arithmetic, but they do not repeat model inference, numerical ANM fitting, source-data ingestion or human benchmark labeling. V3 applies only to the Track A analyzer replay done into a temporary directory; historical `PASS` logs elsewhere do not earn V3 here. The V4 witness recomputation uses the plan's CPT values and independent probability enumeration. The 38-pair bootstrap interval, residual-spread permutations, eigensolver comparison and some archive gate histories remain V1 in this audit. These limits are reflected in the inference-strength column.
